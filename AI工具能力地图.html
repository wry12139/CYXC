三种工具形态

地图里的每一格，都由这三种形态的工具组成：

模型负责推理、生成与分析的基础大语言模型。
MCP通过 Model Context Protocol 接入的实时数据与服务能力。
Skill为特定场景封装的技能模块，通过关键词或命令触发。

MCP 与 Skill 构建在 Claude Code 生态之上；模型层可替换，能按团队习惯换成其他大模型或编码 Agent。

06

现状与建议

能力集中在数据

当前接入的 MCP 均为金融数据服务，Skill 亦以数据类为主，整体重心落在数据获取与分析环节。

部分环节缺少专用 MCP

开发、测试、文档、部署四类目前依赖模型与 Skill 支撑，暂无配套 MCP。如需强化，可按需接入代码托管、文件系统、浏览器自动化等服务。
