# 王仁懿 - 个人在线简历

## 🎯 项目简介

这是一个现代化、交互式的个人在线简历网站，展示个人技能、项目经历和联系方式。采用紫白配色方案，融合三层视差滚动、卡片堆叠等高级交互效果，提供沉浸式的视觉体验。

## 🌐 在线访问

## ✨ 主要特性

### 设计特点
- 🎨 **紫白配色** - 专业优雅的视觉风格
- 📱 **响应式设计** - 完美适配各类设备
- ✨ **三层视差效果** - 滚动时背景、中层、前景分层移动
- 💫 **卡片堆叠动画** - 悬停卡片时多层分离浮起

### 交互功能
- 🖱️ **视差滚动** - 深度感十足的滚动体验
- 🎯 **导航快速跳转** - 右上角固定导航栏，快速定位
- 💫 **进场动画** - 各元素按序出现，流畅自然
- 🔝 **返回顶部按钮** - 方便快速回到顶部

## 🎨 自定义修改

### 修改颜色方案
编辑 `<style>` 中的颜色变量：
- 主色调：`#667eea`（紫蓝）
- 次色调：`#764ba2`（深紫）
- 文字色：`#333`（深灰）

### 修改内容
编辑 HTML 中对应的文本内容：
- 个人信息：`<p class="role">` 和 `<p class="intro">`
- 技能卡片：`<div class="card">`
- 项目卡片：`<div class="project-card">`
- 联系方式：`<div class="contact-items">`
